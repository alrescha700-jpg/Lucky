MP3 lebih kecil dan disarankan untuk storytelling. WAV berukuran jauh lebih besar. Hasil kedua format dibuat dalam proses terpisah agar penggunaan kuota tidak terduplikasi tanpa pilihanmu.

Kuota gratis Azure dan batas pemakaian

Azure Speech F0 mencantumkan 500.000 karakter Neural Text-to-Speech gratis per bulan. F0 membatasi hingga 20 transaksi per 60 detik. StoryVoice membagi teks menjadi bagian maksimal 1.800 karakter dan memberi jeda agar mendekati batas tersebut. Satu naskah 50.000 karakter memakai sekitar 50.000 karakter kuota untuk satu format. Membuat MP3 dan WAV secara terpisah akan memakai kuota dua kali. Kuota dan ketersediaan dapat berubah; pantau pemakaian di Azure Portal.

Catatan: layanan gratis bukan tanpa batas. Azure dapat meminta metode pembayaran untuk verifikasi akun. Jangan bagikan API key. Naskah 50.000 karakter dapat memerlukan beberapa menit karena batas transaksi F0.
